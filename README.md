# Ghost FTP

Ghost FTP is a privacy-first Windows FTP, FTPS and SFTP desktop client maintained in **bren-wp/Host-FTP**.

## Current build

Version: **0.2.0**

Ghost FTP 0.2.0 is the reference-UI release. The Windows interface follows the approved premium dark product direction with a cyan → electric-blue → violet identity and a layout designed for fast server work rather than a legacy FTP-client workflow.

### Reference UI

- integrated Ghost FTP logo and compact wordmark
- wide application navigation rail
- global **Ctrl+K** file/site search entry point
- dedicated Connect / Disconnect / New Folder / Upload / Download / Refresh action bar
- balanced Local Files and Remote Files dual-pane workspace
- remote permissions, rename, delete and remote-edit tools
- persistent Transfer Queue with pause, resume, cancel, retry and clear actions
- expanded Connections / Site Manager experience
- saved-site management, profile duplication and secure credential handling
- transfer safety summary linked to real application settings
- directory comparison, bookmarks, recursive search and remote editing
- high-DPI-aware Windows layout

## Protocols

Ghost FTP supports:

- FTP
- FTPS
- SFTP

## Security and privacy

Ghost FTP does not require a Ghost FTP account and does not add advertising or product telemetry. Saved secrets use the maintained platform protection layer; sensitive credentials are not intentionally written to application logs.
