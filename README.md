# Ghost FTP

Ghost FTP is a privacy-first Windows FTP, FTPS and SFTP desktop client maintained in the **bren-wp/Host-FTP** repository.

## Current build

Version: **0.1.0**

The Windows product uses the approved premium dark Ghost FTP interface:
- wide application rail
- Connections / Files / Transfers / Sync / Settings navigation
- Local Files and Remote Files dual-pane workspace
- persistent transfer queue
- cyan / electric-blue / violet product accents
- native Windows Setup and Portable executables

## Functional scope

The application source includes real local/remote navigation, FTP/FTPS/SFTP connection handling, upload/download queues, retry/cancel/pause lifecycle, bookmarks, file filtering/search, remote edit, directory comparison, rename/delete/create-directory operations and CHMOD where supported.

## Build

GitHub Actions and the repository source produce:
- `Ghost-FTP-0.1.0-Setup.exe`
- `Ghost-FTP-0.1.0-Portable.exe`
- `Ghost-FTP-0.1.0-Source.zip`
- `SHA256.txt`

## Privacy

Ghost FTP does not require a Ghost FTP account and the maintained client does not add advertising or product telemetry.
